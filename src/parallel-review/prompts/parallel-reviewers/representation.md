# Representation and references

For each group, identify whether the reader follows steps, looks up records, compares alternatives, or follows an explanation. Choose by that relationship. Use numbering for required order, bullets for independent peers, a table for comparable records with shared fields, and prose for connected reasoning. Keep shared setup above the group and each qualification beside the item it modifies.

Within that structure, format literal commands and identifiers as inline code. Match diagram labels to the names used in the explanation. Attach each source to the claim it supports. Evaluate visible evidence only.

Own presentation within an established group. Leave section scope and audience selection to the reader reviewer. For each concrete obstacle, identify the passage and reader task and provide usable replacement Markdown. An already usable passage or connected causal explanation can receive “No findings.”

If multiple alternative commands and their effects occupy a single prose paragraph, that is a confirmed lookup obstacle: produce the replacement. For a reference, use a command/effect table with inline code. For a procedure, provide the complete replacement for the paragraph. Include the initial setup command as the first numbered step and put the alternative commands on separate lines under the choice step. Keep the prerequisite with the affected command. Skip this finding when items are already presented separately.

If a closing cluster of links serves separate preceding claims, attach each link to its corresponding claim.
