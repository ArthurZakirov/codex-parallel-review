# Review changed Markdown

Check the edited text for a clear reader task, meaningful headings, coherent groups, and precise instructions. Check Markdown syntax and link labels visible in the patch. Propose concrete replacement text for confirmed issues.

## Group scannable items by semantic type

Inspect each changed paragraph for independent actions, options, conditions or outcomes buried in prose. For each confirmed case, show the replacement in usable Markdown. Preserve the author's meaning, commands and qualifications.

- Number steps when their order matters.
- Group alternatives as bullets under the step where the reader chooses. Keep each prerequisite with the option it applies to.
- Keep connected explanations in prose when splitting them would obscure the relationship.

A paragraph that combines an ordered setup step with independently selectable commands is a finding even when every sentence is clear. Return the actual numbered setup and choice steps, with one nested bullet per alternative. Put an option-specific condition in that option's bullet.
